# EveryFile Converter

> Универсальный конвертер файлов с современным интерфейсом на PySide6.

## ✨ Возможности
- Конвертация PDF в JPG (с настройкой DPI)
- Сборка JPG в PDF
- Конвертация форматов изображений
- Извлечение текста (OCR) из PDF и картинок
- Извлечение аудио (MP3) из видео

## 🚀 Быстрый старт

### Установка зависимостей
```bash
pip install -r requirements.txt
```
### Запуск из исходников
```bash
python main.py
```

### 🛠️ Технологии
Python 3.11+

PySide6 (GUI)

PyMuPDF (работа с PDF)

Pillow (изображения)
